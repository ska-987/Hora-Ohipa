# Bien démarrer avec Hora ‘ohipa

## Installer et mettre à jour

[Télécharger la bêta 1.15](https://github.com/ska-987/Hora-Ohipa/releases/download/v1.15-beta/Hora-Ohipa-beta1.15.apk).

L’application fonctionne sur Android 8 ou supérieur. Ouvrez le fichier APK téléchargé et confirmez l’installation. Android peut demander d’autoriser l’installation depuis la source utilisée.

Pour une mise à jour, **ne désinstallez pas l’ancienne application** : installez la nouvelle APK par-dessus.

## Préparer votre activité

Renseignez votre entreprise, vos clients, vos prestations et votre taux horaire. Vérifiez les paramètres de TVA et les mentions qui doivent figurer sur vos documents.

L’application permet de configurer ces informations ; elle ne choisit pas votre régime fiscal à votre place.

## Pointez, vérifiez, facturez

Enregistrez l’arrivée, les pauses et le départ. Si une plage horaire est incorrecte, corrigez-la avant la facturation. Vérifiez les informations de votre client, puis préparez le PDF.

Les rappels d’arrivée et de départ sont facultatifs. Configurez-les selon votre rythme et autorisez les notifications si Android le demande.

## Conserver vos données

Les données restent sur le téléphone. Utilisez les réglages pour exporter vos données en JSON ou ZIP avant un changement de téléphone ou une désinstallation.

Le partage vers Drive ou une autre application Android est déclenché par vous ; il ne constitue pas une synchronisation automatique.
